# thermalmodelling

English thermal modelling and building performance website at https://thermalmodelling.hu/.

The home-page certification table links to 52 scope guides under `credits/`. Each guide distinguishes the official requirement summary from the proposed engineering inputs, workflow, deliverables and verification responsibilities. Official sources open in new tabs.

`credits/index.html` provides search and certification-system filtering. `credits/review-notes.html` records full-issue versus selected-scope badge distinctions and source-version differences. The existing home-page badges and imagery are preserved; Mat 03 is excluded.

The pages are static HTML with a shared stylesheet at `assets/credit-pages.css`. GitHub Pages publishes from main. Content version references and review dates are stated on the scope pages.
