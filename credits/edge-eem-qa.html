Airtightness & thermography

Airtightness-measure input verification and optional thermographic envelope QA; final evidence requirements remain subject to the EDGE audit pathway.

EEM / QASupporting EEM10 / QA — no credit points

What the requirement covers

Airtightness input verification can support EDGE EEM10, Air Infiltration of Envelope. Thermography is additional envelope QA and is not an independent EDGE points mechanism.

  • Keep EEM10 input verification separate from optional thermography
  • Test pressure and whole-building leakage units cannot be inserted into a model without the correct conversion / definition
  • The guide / auditor controls the accepted evidence for the chosen input

What the project needs to provide

  • Target leakage rate, test stage, access and temporary-sealing plan
  • Thermography conditions, inspection responsibilities and remediation process

Calculation and evidence plan

Infiltration input verification

Distinguish measured pressurisation leakage from the EDGE infiltration parameter. Confirm the required input definition and auditor evidence before converting or entering a test result. Thermography can identify envelope irregularities but does not quantify air leakage by itself.

How I support the assessment

  1. Agree the infiltration input, test boundary, units and auditor evidence route
  2. Coordinate airtightness testing and optional thermal inspection
  3. Reconcile tested findings with model inputs, remedial work and final audit documentation

What I deliver

  • Test / inspection scope and readiness checklist
  • Airtightness and thermal-image findings linked to locations and details
  • Defect register, remedial-action review and retest evidence

Verification and responsibilities

Airtightness measurement and thermographic inspection are different activities. Site conditions, competent testing, remediation and close-out determine the final evidence quality.

Before work starts, agree the assessment boundary, selected route, current design issue and named owner of each missing evidence item. At handover, reconcile the calculations with final products, installed systems and any required test records.
